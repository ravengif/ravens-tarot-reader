# ravens-tarot-reader
<h2><i>A tarot reader and educator made by Raven.gif</i></h2>
<b>
  An in-progress tarot reader that teaches you how to read on your own. Currently, it can do the following: 
  
 1. List all of the cards pulled in a session
 2. Account for common aliases (8 vs eight, etc)
 3. Count elements, card types, etc to log under "Patterns"
 4. Display basic card info (keywords, elements, astrology, etc)

2. Card images

6. Card pairings notes (when "the fool" is paired with "queen of cups", xyz)
